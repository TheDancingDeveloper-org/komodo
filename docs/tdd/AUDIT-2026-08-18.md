# Komodo credential usage audit — Node B

**Date:** 2026-08-18
**Instance:** Komodo Core 2.2.0 on `node-b` (`winrarhost`), reached at `http://100.92.54.45:3011`
**Method:** live read via the Komodo REST API (`ListStacks`, `GetStack`, `ListDeployments`, `ListVariables`, `ListSecrets`), cross-referenced against Infisical secret *names* (`/api/v3/secrets/raw`). No secret values were printed, logged or stored at any point.

## Why this audit exists

Cadastre's record for the `komodo` service already states the problem:

> GitOps deploy controller, core on Node B with peripheries on Node B, Hetzner, Vultr and hetzner3. Production deploys go through it, never ad hoc SSH. **It has no external secret-manager connector, so Infisical values are COPIED into stack environments — a point-in-time copy, and the estate's main silent-staleness source.**

This audit quantifies that claim before acting on it.

The finding that matters: **Komodo's secret-interpolation mechanism exists and is used exactly zero times.** Every credential is a literal copy living in Komodo's MongoDB. There is no link back to Infisical, so nothing detects divergence, and rotating a secret in Infisical has no effect on any running stack until someone edits 1–6 stack definitions by hand.

## Two honest caveats

1. **180 is an upper bound.** The classifier matches on key *name* (`SECRET|TOKEN|PASSWORD|KEY|PAT|...`), and it over-captures. `CROSSSEED_TORRENTLEECH_ENABLED`, `CROSSSEED_SEED_MOVE_DIR`, `CROSSSEED_LUMINARR_RSS_URL` and the various `*_NICK` entries are configuration, not credentials. The true credential count is somewhat lower and needs a human pass.

2. **106 "no exact match" is a naming problem, not a gap.** Most of those values almost certainly *do* exist in Infisical under the estate's `HOMELAB_*` convention (`POSTGRES_PASSWORD` in a stack vs `HOMELAB_STACKARR_POSTGRES_PASSWORD` in Infisical). This is a name-mapping workload, not 106 missing secrets. Treat the number as the size of the mapping exercise.

## Reproducing

The audit is read-only and safe to re-run:

```bash
mydevenv2-agent-auth run -- python3 scripts/tdd/audit-komodo-secrets.py /tmp/audit.json
```

## What this justifies

The integration described in [`DESIGN.md`](DESIGN.md): resolve secrets from Infisical at deploy time so a stack holds a *reference* rather than a *copy*, which removes the drift class entirely and makes rotation a single Infisical write.
